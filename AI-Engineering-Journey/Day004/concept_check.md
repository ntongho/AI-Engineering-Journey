# Day 004 - Concept Check

## Question 1
What does input() do?

**Answer:**
input takes user input/entry. Its basically for interactivity purpose and it returns a string by default 

---

## Question 2
Why does input() return a string?

**Answer:**
String happens to be its default return format since it reads value from the keyboard 
---

## Question 3
What does int() do?

**Answer:**
Int() is basically for type conversion to integer. So if an input is wrap with this, it converts your value to an integer 

---

## Question 4
When would you use float()?

**Answer:**
float() is basically for type conversion to floating point numbers(decimal). So if an input is wrap with this, it converts your value to a decimal/floating point number 
---

## Question 5
Why do we store the result of input() in a variable?

**Answer:**
We store user input in a variable so we can reuse the value later in the program.
