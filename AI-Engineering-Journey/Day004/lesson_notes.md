input()
input takes user input/entry. Its basically for interactivity purpose and it returns a string by default 
String happens to be input() default return format since its reads value from the keyboard 

Int() 
is basically for type conversion to integer. So if an input is wrap with this, it converts your value to an integer 

float() 
is basically for type conversion too but to floating point numbers(decimal). So if an input is wrap with this, it converts your value to a decimal/floating point number 

Why input() returns a string
Inputs are stored in a variable so its value can be used,remembered and easily picked in memory
