Inheritance is an object-oriented programming (OOP) mechanism that allows a new class to reuse, modify, and extend the attributes and methods of an existing class

Parent Class: The existing class whose code is being copied and shared.

Child Class : The new class that automatically receives the features of the parent class.
Base Class:  Another name for a Parent Class.

Derived Class : Another name for a Child Class.

Method Overriding : When a child class redefines a method from the parent class using the exact same name to customize its behavior.

super():A built-in tool used inside a child class to call and run code directly from the parent class, avoiding code repetition
