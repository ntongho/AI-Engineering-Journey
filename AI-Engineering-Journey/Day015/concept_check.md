# Day 015 - Concept Check

## Question 1
What is inheritance?
**Answer:**
A programming mechanism where a new class adopts the attributes and methods of an existing class
---

## Question 2
Why is inheritance useful?
**Answer:**
 It eliminates code duplication by allowing multiple classes to reuse common functionality from a single source.
---

## Question 3
What is a parent class?
**Answer:**
The original base class (or superclass) that shares its existing properties and behaviors with other classes.
---

## Question 4
What is a child class?
The specialized derived class (or subclass) that inherits functionality from a parent class and can add its own features
---


## Question 5
What is method overriding?

**Answer:**
A feature allowing a child class to rewrite or redefine a specific method it inherited from its parent class.
---

## Question 6
What does super() do?
**Answer:**
 It acts as a shortcut to reference and trigger methods or constructors directly from the parent class.
 
## Question 7
When would you use inheritance?
**Answer:**
You use it when a clear "is-a" relationship exists between a specific object and a broader category (e.g., a Car is a Vehicle)

## Question 8
Can a child class have additional methods?
**Answer:**
 Yes, a child class can freely introduce completely new methods that do not exist in the parent class.

## Question 9
Can a child class replace a parent's method?
**Answer:**
Yes, by using method overriding, a child class can fully swap out or modify the behavior of a parent's method.
