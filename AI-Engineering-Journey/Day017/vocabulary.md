Abstraction: Hiding complex internal details and showing only essential features.
Abstract Class: A partial template that cannot be made into an object; it dictates structure for its child classes.
Abstract Method: A placeholder function with a name but no code, forcing child classes to define its behavior.
ABC (Abstract Base Class): The technical tool in a language (like Python) used to build and enforce abstract classes.
Interface: A strict blueprint or contract listing behaviors a class must support, without providing any code.
Implementation: The actual code written to make a method or interface work.
Encapsulation: Bundling data and methods together while hiding the inner workings from outside tampering.
Concrete Class: A finished, fully coded class that you can actually use to create real objects.
