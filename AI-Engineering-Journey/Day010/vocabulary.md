File:
A file is just a place in ones computer where information is stored

File Handling:
This is simply how the information on this files are created, updated or deleted.

Read Mode:
This is a node that helps you view the content of a file. represented as "r" e. with open("file_name","r") as file

Write Mode:
This is a node that helps you write and also overwrite to a file. represented as "w" e.g with open("file_name","w") as file

Append Mode:
This is a node that helps you write to a file. It does not overwrite the content of file.  represented as "a" e.g with open("file_name","a") as file

open():
This simply opens a file before it can be worked on 

read():
This helps you read the content of a file

write():
This helps you write data to a file.

with open():
This python method helps to open a file
