Loop: 
Loop simply means repeating a block of code

while loop:
This is a type of loop used when you are uncertain of the end point e.g keep runing until user says quit, keep asking input until user gets it right, etc

for loop:
For loop is a type of loop used in python when you know the end point e.g 1-100, Reading all lines in a file


range(): 
Range helps you get a list of numbers. In python, range has a concept where it sees the first range value and excludes the last value e.g if you want to print a range of values range(1,5); it prints 1,2,3 and 4 excluding 5

Infinite loop: 
This is a situation whereby a loop has no end 

Loop variable: 
Loop variable mostly used in a for loop, helps gets individual elements in a loop one after the other so it can easily be used or read
