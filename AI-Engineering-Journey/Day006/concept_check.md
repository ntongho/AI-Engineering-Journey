# Day 006 - Concept Check

## Question 1
What is a loop?
**Answer:**
loop in programming is a concept used when it comes to repetition of a block of code. e.g imagine wanting to print a name on the screen 1000 times. You dont type print(name) 1000 times.
---

## Question 2
What is the difference between a for loop and a while loop?
**Answer:**
both are used for repetition but for loop is used when your end point is known or you know the the number of time you want to repeat something e.g 1-100. While loop is used when you are not certain of the end point or donot know the number of time you want to repeat something. e.g print incorrect password until user enters the right password
---

## Question 3
What does range(5) produce?
**Answer:**
range(5) produces 0,1,2,3,4
---

## Question 4
Why does range(5) start at 0
**Answer:**
Python uses zero-based indexing in many places, so range(5) begins at 0 unless a different starting value is provided.
---

## Question 6
How can you avoid creating an infinite loop?
**Answer:**
By setting a breaking point/condition. In a while loop, you usually update the variable involved in the condition so it can eventually become False
