## Question 1
What is a function?
**Answer:**
Function is a block of code that performs a particular task
---

## Question 2
Why do functions exist?
**Answer:**
Functions exist to organize code, avoid repetition, improve readability, and allow code to be reused.
"Reduce ambiguity" can be one benefit, but it's not the main reason functions exist.
