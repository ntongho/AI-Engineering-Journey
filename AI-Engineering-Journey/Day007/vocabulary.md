Function: 
Function is a block of code that performs a certain task

Function definition: 
The statement used to create a function using the def keyword.

Function call: 
This refers to Running or executing a function by using its name followed by parentheses.

Parameter: 
This is a placeholder inside the function definition

Argument: 
This refers to the actual value you pass into the function

Return value: 
return is used inside a function to send a result back to the code that called it

Scope: 
 refers to a specific part of a program where a variable is visible or accessible

Modulus operator (%): 
This is used to get the remainder of a division
