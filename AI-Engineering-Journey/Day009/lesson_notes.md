Dictionaries
Definition: Collections storing data in unique key-value pairs.
Syntax: Created using curly braces, like my_dict = {"key": "value"}.
Keys & ValuesKeys: Unique identifiers used to look up data.
Values: The data associated with a key, which can be duplicated.
Dictionary Methods
keys(): Returns a view of all keys.
values(): Returns a view of all values.
items(): Returns a view of all key-value pairs as tuples.

Sets
Definition: Unordered collections of unique elements.
No Duplicates: Automatically filters out any repeated items.
Dictionary vs List
Dictionary: Finds items instantly using unique keys.
List: Finds items by their position index number.
