# Day 009 - Concept Check

## Question 1
What is a dictionary?
**Answer:**
A dictionary is an unordered collection that stores data in unique key-value pairs.
---

## Question 2
Why are dictionaries useful?
**Answer:**
They allow you to look up data instantly using descriptive labels instead of memorizing index position numbers.
---

## Question 3
What is the difference between a key and a value?
**Answer:**
A key is a unique identifier used to find data, while a value is the actual data attached to that key.
---

## Question 4
How do you add a new key to a dictionary?
**Answer:**
You add a new key using square brackets and assigning it a value, like my_dict["new_key"] = value.
---

## Question 5
What does items() return?

**Answer:**
It returns a view object containing all the key-value pairs as individual tuples.
---

## Question 6
What is a set?
**Answer:**
A set is an unordered collection of items where every element must be unique.


## Question 7
Why are sets useful?
**Answer:**
They are useful for automatically removing duplicate data and for checking if an item exists quickly.


## Question 8
What happens if you add duplicate values to a set?

**Answer:**
The set will automatically ignore the duplicate values and only keep one copy of the item.

## Question 9
When would you choose a dictionary instead of a list?
**Answer:**
I would choose a dictionary when my data needs descriptive labels to make sense, rather than just an ordered list of items.
