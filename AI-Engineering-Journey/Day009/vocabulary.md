Dictionary is a collection that stores data in key–value pairs, where each unique key points to a specific value
Keys must be unique and cannot be duplicated.
keys() returns a list of all keys.
Key-Value Pair: The basic unit of a dictionary, written as key: value
values() returns a list of all values.
items() returns all key–value pairs.
Duplicate value : While keys must be unique, values can be repeated. Multiple keys can share the same value.
