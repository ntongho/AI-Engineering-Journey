Polymorphism:
 This simply means one interface, different forms

Method Overriding:
    is a programming feature that allows a child class to provide a specific implementation of a method that is already defined in its parent class.

Duck Typing:
    a programming concept where an object's suitability is determined by the presence of certain methods and properties, rather than its actual inheritance or class type

Interface:
    is a programming blueprint that defines a strict set of methods a class must implement, without providing the actual code for those methods.

Dynamic Dispatch:
    is the process where a programming language selects which specific implementation of a polymorphic method to call at runtime, rather than at compile-time.
