OOP:
A software design style organizing code into reusable, real-world structures.
Classes:
The master blueprint or template defining data and behaviors.
Objects:
The actual, functional entity built from a class blueprint.
Constructors:
The setup function (__init__) that assigns starting data automatically.
Attributes:
The variables or data characteristics stored inside an object.
Methods:
The functions or actions an object can actively perform.
self:
The placeholder nickname pointing to the current specific object.
