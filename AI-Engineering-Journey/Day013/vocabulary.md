OOP: Software design based on real-world entities.
Class: The blueprint or master code template.
Object: The actual item built from the blueprint.
Instance: A specific individual copy of an objec
Attribute: A variable or characteristic of an object.
Method: A function or action an object performs.
Constructor: Code that builds and initializes an object.
__init__: Python's specific name for its constructor.
self: A nickname pointing to the current object.
