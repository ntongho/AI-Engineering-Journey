# Day 013 - Concept Check

## Question 1
What is OOP?
**Answer:**
 A software design style that groups data and behaviors into reusable, real-world-inspired structures.
---

## Question 2
What is a class?
**Answer:**
The master blueprint, recipe, or template that defines a specific type of entity.
---

## Question 3
What is an object?
**Answer:**
The actual, functional entity created in memory using a class blueprint.
---

## Question 4
What is the purpose of __init__()?
**Answer:**
It is Python's constructor method, used to automatically assign starting data when an object is born
---

## Question 5
What does self represent?

**Answer:**
A placeholder nickname pointing directly to the specific object currently being worked on.
---

## Question 6
What is the difference between an attribute and a method?
**Answer:**
Attributes are the data variables (nouns), while methods are the actions or functions (verbs)



## Question 7
What is an instance?
**Answer:**
 An individual, specific copy of an object created from a class.

## Question 8
Why is OOP useful?
**Answer:**
 OOP helps organize code into reusable, maintainable, and scalable objects, making large software projects easier to build and manage.

## Question 9
Can one class create many objects? Explain.
**Answer:**
Yes. A single blueprint can stamp out infinite unique objects, each holding its own independent data
