Memory (RAM) is the temporary storage the computer uses to hold data and objects while a program is running.
An object is a piece of data created by Python, such as a number, string, list, or boolean, that exists in memory
A variable is a name that refers to an object in memory.
The difference between = and == = assigns a value to a variable. == compares two values to check if they are equal.
type() tells us the type of the object that a variable refers to.
id() returns the unique identity of the object for the current Python session.
