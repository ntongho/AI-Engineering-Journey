# Day 008 - Concept Check

## Question 1
What is a list?
**Answer:**
List is a collection of multiple values stored in a single variable
---

## Question 2
Why are lists useful?
**Answer:**
Lists allow us to store and manage multiple related values in one variable, making programs simpler and easier to maintain.
---

## Question 3
Why does indexing start at 0?
**Answer:**
This is because python follows a zero based indexing format
---

## Question 4
What does append() do?
**Answer:**
Append is used to add an item to the end of a list. 
---

## Question 5
What is the difference between remove() and pop()?

**Answer:**

Remove() removes an item by value
pop() removes an item by position

---

## Question 6
What is a tuple?
**Answer:**
A tuple is similar to a list but the only difference is that it is immutable


## Question 7
What is the difference between mutable and immutable?
**Answer:**
Mutable simples means object can be changed or altered while immutable means object cannot be changed or altered


## Question 8
When would you choose a tuple over a list?

**Answer:**
I would use a tuple when I have data that should not change, such as the days of the week, months of the year, or GPS coordinates.

## Question 9
How do you loop through a list?
**Answer:**
The best way to loop through a list is using a for loop
