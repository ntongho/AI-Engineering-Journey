List : This is a collection of multiples values stored in single variable
Element : refers to properties or values that make up a list
Index : Refers to position of values in a list 
Mutable : Simply means element can be altered or change
Immutable : Simply means element cannot be altered or change
Tuple : Tuple is list whose elements can not be changed or altered. Its immutable
append() : is used to add an item to the end of a list.
insert() :insert is used to add  item to a list at any specific index
remove() : this is used to delete an item on a list 
pop() : POp is used to remove element from a list. BY default it removes the last element of a list unless you specify the index to take out 
sort() : This is used to sort a list which is usually by ascending order by default
