Exception: An error or unexpected event that occurs while a program is running.

try : This is the code block where you run risky codes

except : This checks the risky code and points out any error the try block encounters

finally : This runs the code regardless of whether an error happens or not

ValueError: This occurs when a function receives an argument that is different from what it is expecting. Mainly difference in data type

ZeroDivisionError: Triggers when you attempt to divide a number by zero

FileNotFoundError : Triggers when your code try to open or read a file that does not exist

raise: This keyword is used to intentionally trigger an error
