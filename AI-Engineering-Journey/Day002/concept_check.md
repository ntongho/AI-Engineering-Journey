# Day 002 - Concept Check

## Question 1
What is programming?

**Answer:**
Programming is the process of designing and writing instructions that tell a computer how to solve a problem or perform a task.

---

## Question 2
Why do computers need programming languages?

**Answer:**
A programming language allows humans to write instructions in a readable form, which are then translated into machine language.

---

## Question 3
What is the Python Interpreter?

**Answer:**
Its simply a translator that reads,translates and executes python language to machine language which the computer understands

---

## Question 4
Why is Python used for AI?

**Answer:**
Python is used in AI because of some of its libraries that can be used to build sophisticated AI systems and also its level of simplicity and readability

---

## Question 5
What happens when you press Run?

**Answer:**
When I press Run, Python reads my program, translates each instruction into machine instructions, the CPU executes those instructions, and the result is displayed.
