# Lesson Notes - Day 002

## Programming

Programming is the process of giving a computer instructions to solve a problem.

---

## Programming Language

A programming language allows humans to communicate with computers in a readable format.

Examples:

- Python
- Java
- C++
- JavaScript

---

## Python

Python is a high-level programming language created by Guido van Rossum.

It is widely used because it is:

- Easy to read
- Easy to write
- Powerful
- Flexible

---

## Python Interpreter

The Python Interpreter reads Python code, translates it into machine instructions, and executes it.

---

## What Happens When I Press Run?

1. Python opens the file.
2. Reads the code.
3. Translates instructions.
4. CPU executes them.
5. Output appears.
