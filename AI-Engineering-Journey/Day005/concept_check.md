## Question 1
What is a Boolean?

**Answer:**

## Question 2
What is the purpose of an if statement?

**Answer:**
An if statement checks whether a condition is True. If it is, Python executes the corresponding block of code.
---


## Question 3
What is the difference between if, elif, and else?

**Answer:**
if → checks the first condition.
elif → checks additional conditions if previous ones were false.
else → runs when none of the previous conditions are true.
