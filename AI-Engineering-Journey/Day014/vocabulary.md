

Instance Method: Uses self. Accesses individual object data.
Class Method: Uses @classmethod and cls. Accesses class-wide data.
Static Method: Uses @staticmethod. Utilitarian function with no object or class access.
Class Variable: Declared in the class body. Shared by all instances.
Private Attribute: Prefix __. Hidden from direct external access.
cls: Parameter in class methods. Points to the class blueprint
Encapsulation: Bundling data and methods together. Restricts direct outside access.
