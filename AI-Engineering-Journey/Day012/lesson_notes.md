Modules: Single Python files containing code you can reuse.
Importing: The process of bringing external code into your current file.
Aliases: Alternative, shorter nicknames given to imported modules to save typing.
Standard Library: A massive collection of ready-to-use modules built directly into Python.
Packages: Directories containing multiple modules grouped together under one name.
__name__ == "__main__": A check ensuring code runs only when the file is executed directly.
