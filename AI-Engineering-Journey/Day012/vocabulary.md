Module:
Is simply a python file with code that is reuseable 
Package:
Pack simply refers to a folder containing modules
Import:
This is a keyword used to call a module or a function in a module 
Alias:
A temporary alternative name given to an imported module or function

Standard Library:
This are prebuilt in module that comes directly with a programming language like python

__name__
This is a special built in variable that evaluates to the name of the current module 
__main__
This is the specific string assigned to the special __name__ variable when a python script is executed as a top level program
