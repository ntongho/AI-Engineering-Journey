# Day 012 - Concept Check

## Question 1
What is a module?
**Answer:**
 A file containing Python code, functions, and variables
---

## Question 2
Why are modules useful?
**Answer:**
They help organize code and let you reuse it in other files.
---

## Question 3
What is the difference between import module and from module import function?
**Answer:**
import module loads the whole file; from module import function loads only a specific piece.
---

## Question 4
Why would you use an alias?
**Answer:**
To make long names short or avoid naming clashes
---

## Question 5
What is the Python Standard Library?

**Answer:**
A large collection of ready-to-use modules built right into Python
---

## Question 6
What is a package?
**Answer:**
A folder of multiple Python modules grouped together.


## Question 7
What does __name__ represent?
**Answer:**
A special variable that holds the name of the current module.

## Question 8
Why do programmers use if __name__ == "__main__":?
**Answer:**
To run code only when the file runs directly, not when another file imports it.

## Question 9
Name two standard library modules you've used today.
**Answer:**
math and random are two common examples.
